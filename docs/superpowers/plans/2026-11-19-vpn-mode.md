# VPN Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Make capture work with a VPN on by adding/removing the downloader proxy on the VPN service via a root guard.
**Architecture:** `VPNMode.swift` in DownloaderCore holds the guard script, the osascript command builders and scutil parsers; `DownloaderController` launches the guard after Start when a VPN is primary and reports routing state; `StatusBarView` shows the strip and buttons.
**Tech Stack:** POSIX sh + scutil (root, via osascript), Swift, Swift Testing (guard run against a fake scutil).
**Spec:** `docs/2026-11-19-vpn-mode-design.md`

## Global Constraints
- Guard marker string `channels-vpn-guard`; proxy 127.0.0.1:2023; poll 2 s (env `GUARD_INTERVAL` for tests); scutil path `${SCUTIL:-/usr/sbin/scutil}`.
- osascript args: script text and pid passed as argv items, never interpolated into AppleScript source.

## Review Focus
1. Guard never clobbers or removes a foreign Proxies entry.
2. Malformed PrimaryService values are ignored (no injection into scutil commands).
3. Downloader exit (any cause) removes the guard's entries.
4. Password refused → app keeps running, offers "Enable VPN mode", no crash.
5. Leftover VPN proxy after a guard death is detected and fixable.
